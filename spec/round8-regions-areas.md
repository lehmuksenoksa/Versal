# Round 8: regions or areas

You picked this to explore next. Round 4 kept 20 regions, but a run is about ten levels in three or
four regions. Round 5 asked whether some are better as areas (a part of a level, inside a
region). One question each:
- **Region:** whole levels of it.
- **Area:** a part of a level, found inside regions.
- **Either:** sometimes one, sometimes the other.
- **Drop.**

Which regions a run goes through, and in what order, is a later question. So is everything inside
each.

## Same regions every run?

A separate question. With more regions than a run can go through:

| | Option | In a line |
|---|---|---|
| A | The same every run | The same three or four regions in the same order |
| B | Drawn from a pool by depth *(my pick)* | Each stage of the run draws one region from the few that fit that depth |
| C | Drawn freely | Any region at any depth |

**Why B:** your principles ask for surprises on each run. B gives a different run each time while
keeping a rise in danger from top to bottom.
