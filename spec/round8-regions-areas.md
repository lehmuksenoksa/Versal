## Same regions every run?

| | Option | In a line |
|---|---|---|
| A | The same every run | The same three or four regions in the same order |
| B | Drawn from a pool by depth *(my pick)* | Each stage of the run draws one region from the few that fit that depth |

**Why B:** your principles ask for surprises on each run. B gives a different run each time while
keeping a rise in danger from top to bottom.
