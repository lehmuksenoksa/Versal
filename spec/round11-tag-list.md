# Round 11: tags, shallow

"Magic user, Intelligent (can open doors for example), Aggressiveness levels, Venomous, we could
brainstorm more, enough for all monsters."

Tags, one line each, grouped by sort, to keep, maybe or drop. A type's own tags and its extras come
from this one list. Later questions, each its own:
- which tags are for a type and which for extras;
- which types have which;
- the numbers behind each;
- how each shows.

The sorts from round 10 are here, and the ones you added: mind, temper, attacks, magic. Some sorts
have more besides: defence, life, deceit. Today's traits are marked *(in the game)*.
